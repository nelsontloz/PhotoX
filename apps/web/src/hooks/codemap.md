# apps/web/src/hooks/

## Responsibility

Reusable hooks that fetch/group data and drive the asset viewer. Hand-rolled data fetching on top of `src/api` (no react-query/SWR): each hook owns `loading`/`error`/data locally and exposes an explicit `refresh()`.

## Design

- `useAssetGroups(opts: { isTrashed?, favorite?, dateField?: 'takenAt'|'trashedAt' })` — fetch-ALL mode, unchanged: pages `listAssets` at 50/request until `total`, then `groupAssetsByDay(all, dateOf)` (exported pure helper: sort by date desc, bucket by `groupDateSortKey`, labels via `groupDateLabel`). `fetchIdRef` guards against stale responses when refetches overlap. Subscribes to `useAppStore.timelineRefreshKey`. Used by `favorites` and `trash` only — the timeline moved to `useTimelineMonths`.
- `useTimelineMonths()` — the timeline's per-month cache: `Map<monthKey, { items, status: 'loading'|'ready'|'error', stamp }>` with **no fetch at mount**. `ensureMonth('YYYY-MM')` is deduped per key via an in-flight `Map` (a promise from an older refresh-key stamp is ignored and refetched), pages `listAssets({ limit: 50, dateFrom, dateTo })` (local-midnight half-open range from `monthRange`) until `total`, and commits `{ items, status: 'ready', stamp }`. `stamp` = `timelineRefreshKey` at fetch start; commits with a stale stamp are dropped (per-key staleness guard), while the previous items stay visible across a bump so the viewer never unmounts. `groups` merges every entry's items through `groupAssetsByDay` (stale entries included); `monthStatus` feeds skeleton decisions; a failed month resolves `null` (never rejects), keeps its previous items and retries on the next trigger — ponytail: no per-month error UI.
- `useTimelineLayout()` — reserves the timeline's full scroll track before any month loads. Fetches `GET /v1/assets/layout` (re-running on `timelineRefreshKey`, first load only gates via `loadedOnceRef`), measures `containerWidth` with ONE ResizeObserver on the grid container (the returned `containerRef` also measures synchronously during commit so first paint is correct), and reads `rowHeight` from computed CSS through a hidden probe carrying `.fixed-row-gallery` (never `innerWidth` — the CSS breakpoint is `40rem`, which diverges from px when root font-size ≠ 16px). Builds buckets with `lib/timelineLayout.buildBuckets` from the layout endpoint's items **only** — it is the single source of heights (ponytail: no rebuild-from-actual-assets path; partial months would shrink the reserved track — upgrade path: rebuild only if every month is loaded). Exposes `layoutItems` (raw effective-date desc list) for the viewer's beyond-the-loaded-set navigation. Returns `{ layout, layoutItems, containerRef, loading, error }`.
- `useAlbums()` — loads the first 1000 albums once; `create`/`update`/`remove` call the API then re-fetch the whole list; `remove` asks `window.confirm` ("Assets in it will not be deleted"). Returns `{ albums, total, loading, error, refresh, create, update, remove }`.
- `useAlbumAssets(albumId, pageSize = 60)` — loads the first page of an album's assets; `addAssets`/`removeAsset` mutate then re-fetch; `removeAsset` confirms via `window.confirm`. No pagination beyond page 1 (ponytail-sized for personal libraries).
- `useAssetNavigation({ assets, onAfterAction, hasBeyond?, resolveBeyond?, resolveMissing? })` — no fetching by default: the `?asset=<id>` search param is the single source of truth for the open viewer. Derives `selected` by id lookup (ignores stale ids not in the given list) and `hasPrev`/`hasNext` by index. `open`/`goPrev`/`goNext` rewrite the param; `close` clears it. `trash`/`restore`/`permanentlyDelete`/`toggleFavorite` call the assets API, close the viewer and `await onAfterAction()` (typically a `refresh`); destructive ones `window.confirm` first and `window.alert` on failure. The three optional callbacks are the timeline's partial-data edges, all omitted by favorites/trash/albums (identical index-walk behavior): `hasBeyond(dir, fromT)` asks the layout whether items exist past the loaded set (keeps arrows enabled at the boundary); `resolveBeyond(dir, fromT)` loads the adjacent month (`ensureMonth` on the layout neighbour's timestamp) and resolves the adjacent asset to step to — `goPrev`/`goNext` route through it at the loaded boundary OR across a calendar gap (`monthDistance > 1`, possible after a deep link); `resolveMissing(id)` fetches a deep-linked asset whose month was never loaded. Resolved assets land in a `fallback` state (batched with the param write) so `selected` resolves immediately and the viewer never unmounts while the month commits; covered by `useAssetNavigation.spec.tsx` (MemoryRouter).
- `useLongPress(callback, ms = 500)` — touch-only long-press: arms a timer on `pointerdown` only when `pointerType === 'touch'`, clears on up/leave/cancel, and exposes `justLongPressedRef` so the following click can be suppressed; `onContextMenu` prevents the native menu while armed. Used by `GalleryItem` for multi-select.
- Error convention across hooks: `(err as Error).message ?? '<fallback>'` into local `error`; mutations use native `confirm`/`alert`, not toast infrastructure.

## Flow

1. Mount/param change → hook effect → `src/api` call(s) → local state (`loading` → data / `error`).
2. Mutations call the API then `refresh()` — no optimistic updates, no client cache; the returned `refresh` is also passed as `onAfterAction` to `useAssetNavigation`.
3. `timelineRefreshKey` bumps: `useAssetGroups`/`useTimelineLayout` refetch outright; `useTimelineMonths` only invalidates stamps and the grid re-triggers `ensureMonth` for visible months. `useAssetNavigation` reacts only to URL changes (plus one-shot `resolveMissing`).

## Integration

- Talks to `src/api/assets.ts` and `src/api/albums.ts`; formats dates via `src/lib/dateFormat`.
- `pages/*` compose these hooks; `AssetViewer` receives `selected` plus nav/action callbacks; `TimelineGrid` types against `AssetGroup`.
- `useAppStore` is the only store these hooks touch directly; auth is enforced upstream by `RequireAuth`, not by the hooks.
- Tests: `useAssetNavigation.spec.tsx` (MemoryRouter) and `useTimelineMonths.spec.tsx` (month-range instant math + cache dedupe/invalidation/staleness, `listAssets` mocked) only.
